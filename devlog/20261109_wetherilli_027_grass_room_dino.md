# 027 — 잔디 방: 고사리와 작은 공룡, 햄부기도 사막 방

2026-11-09 · `work/20261109-wetherilli` · wetherilli

사용자: 「paleoadmin/WegenersDream 부서는 잔디 깔아주고, 조그만 공룡이 돌아다니게 해줘. 관련 대사도 채워주고. 고사리도 조금 자라있게」,
「부서 이름도 고지리생태학 연구실로」, 「햄부기 부서도 전에 선호와함께춤을 부서에서 갖고 있던 특징들 그대로」.

## 한 것

- **방 열쇠로 꾸밈** — 사막 방(024)과 같은 길. `world.ts` 의 `GARDEN`(지금 `paleoadmin/WegenersDream`)이면 `office-fern` 모듈.
  `themeOf(room)` 하나로 사막·잔디를 가른다(잡담의 `Who.theme`).
- **부서 이름** — 화면에서 두 번 눌러 고치는 것과 같은 `PUT /api/people {room, name}` 으로 「고지리생태학 연구실」. 코드가 아니라 rooms.json 의 값이다.
- **바닥** — 칸마다 초록 넷 중 하나인 얇은 판(이음매 없이), 풀 포기 90군데(세 갈래 원뿔), 둥근 맨땅 넷, 흰·노랑 작은 꽃. 자리로 정한 의사난수라 굽기마다 같다. 격자 선은 긋지 않는다.
- **고사리** — 공룡 울타리의 `fern` 을 크기 인자로 1.5배, 안쪽에 곧은 새순 넷을 더해 덤불처럼. 양옆 벽 앞·앞 칸막이 구석·왼쪽 책상 옆 여섯 포기.
  문 옆(출입구 x 2.8~4.2)은 비운다. 둥지(알 셋)와 바위 하나도.
- **공룡** — 울타리의 콤프소그나투스 그림(dinos.webp)을 그대로 쓴다(새로 굽지 않는다), 청록 하나. `iso/garden.ts`.
  잔디 위를 종종걸음(0.85/초), 두리번, 고사리 앞에 가서 뜯기(35% — 뜯다 가끔 고개를 든다), 사람 발치로 가서 올려다보기(20%).
  뜯는 자리는 다니는 곳 안에서 그 고사리에 가장 가까운 점 — 0.8 보다 먼 것(책상 옆 고사리)은 뜯으러 가지 않는다.
- **대사** — 공룡이 1.1 안에 오면 `DINO_NEAR`(「꼬리 조심~」·「손가락은 먹이가 아니야!」), 고사리 뜯는 걸 2.2 안에서 보면 가끔 `DINO_FERN`.
  사막 방의 놀람과 같은 말풍선 자리(`startled`)를 쓰고, 한 번 말하면 40~90초 쉰다 — 놀람보다 덜 급한 말이라 조금 길게.
  그 방 사람의 잡담엔 `FERN_DIALOGS`·`FERN_SOLO`(판게아·베게너·곤드와나 고사리 화석, 공룡 이름 짓기)가 섞인다 — 비율은 사막과 같다.
- **햄부기(shkim/houdini)도 사막 방** — `DESERT` 에 하나 더. 모래·선인장·전갈·걷는 선인장·낡은 벽지·거미줄·기운 명판이 모두 따라온다.
  사막 대사의 「선호와 함께 춤을」 두 군데는 `{방}`(그 사람의 부서 이름)으로 — 햄부기 사람이 남의 부서 이름을 말하지 않게.
- 시험 — 잔디 방이 지어지고 공룡 길이 걸음 막기와 겹치지 않으며 뜯는 자리가 고사리에 닿는지(world.test, 벽 넘기 시험에도 잔디 방을 넣었다),
  공룡이 다니는 곳 안에서 고사리를 뜯고 사람 발치에 가는지(garden.test).

## 버린 것

- **공룡을 새로 더 작게 굽기** — 콤프소그나투스가 이미 무릎 높이(0.5)라 「조그만 공룡」이다. 같은 그림을 쓰면 굽기·시트가 늘지 않는다.
- **흙 자국을 네모 판으로** — 첫 판이 상자처럼 보여서 납작한 타원 원판으로.
- **책상 사이 고사리** — 사람이 의자로 가는 길(책상 사이 x 2.95~4.05)을 막아 뺐다.
- **꾸밈을 부서 이름으로 고르기** — 024 와 같은 까닭(이름은 사람이 고친다).
