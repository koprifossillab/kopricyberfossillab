# 017 — 목록에서 이름 두 번 눌러 고치기

2026-10-24 · `work/20261024-wetherilli` · wetherilli

사용자: 「에이전트 칸에서 직원들 이름 더블클릭하면 그자리에서 수정할 수 있게 해줘」.

## 한 것

- `names.ts` 에 고친 이름 표(id → 이름)를 두고 `personName` 이 그것을 먼저 본다. 그래서 목록·고른 에이전트·화면 이름표·말풍선·상담원 대화창이
  한 곳만 고쳐도 같이 바뀐다. 화면(Stage)은 프레임마다 `personName` 을 부르니 따로 알릴 것이 없고, React 쪽은 `useSyncExternalStore` 로 다시 그린다.
- 목록 줄의 이름(`<b>`)을 두 번 누르면 입력란. Enter·바깥 누르기 = 정함, Esc = 그만, 비우면 지어 준 이름으로 돌아간다(표에서 지운다). 20자까지.
  한글 조합 중의 Enter(`isComposing`)는 정함으로 치지 않는다 — 마지막 글자가 잘린다.
- 줄이 `<button>` 이었는데 입력란은 button 안에 둘 수 없다(스페이스가 줄 누르기로 새고 HTML 로도 틀림) → `div role=button tabIndex=0` + Enter·스페이스로 고르기.

## 버린 것

- **서버에 저장** — 이 앱은 원천을 읽기만 하고 DB 도 없다. 이름 하나 때문에 쓰는 길을 내지 않았다. 대신 이름은 **이 브라우저에만** 남는다(localStorage `kopricyberfossillab.names`).
  다른 사람·다른 브라우저에서는 지어 준 이름 그대로다.
- **화면의 캐릭터 이름표를 두 번 눌러 고치기** — 화면 두 번 누르기는 이미 「처음대로」(확대 풀기)다. 목록에서만.

id 가 세션마다 정해지므로, 세션이 끝나고 새로 뜨면(새 id) 새 이름을 받는다. 고친 이름 표는 지우지 않고 쌓인다 — 이름 몇 글자라 둔다.
