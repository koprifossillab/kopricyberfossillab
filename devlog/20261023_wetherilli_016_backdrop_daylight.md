# 016 — 바깥 배경: 3층 빌딩의 최상층, 낮과 밤

2026-10-23 · `work/20261023-wetherilli-backdrop` · wetherilli

사용자: 「바깥 배경을 2D 이미지로 깔아서 3층 정도 되는 빌딩의 최상층 느낌으로」, 이어서 「실제 시간을 참고해서 밤에는 어두운데 조명이 켜지고, 낮에는 밝게, 연속적으로」.
fl-agent-office-3d 세션이 나눠 맡겼다 — 이 글은 새 파일 `web/src/iso/backdrop.ts` 하나(+ 미리보기). 화면에 붙이기(Stage)와 실내 조명은 그 세션이 한다.

## 한 것

- `drawBackdrop(ctx, proj, world: {w, d}, view: {x0, y0, x1, y1}, t, daylight)` — Stage 가 캔버스를 지우고 구운 픽셀 변환을 건 뒤, 모듈 바닥보다 먼저 부른다.
  1. **하늘** — 밤 남색 ↔ 낮 하늘색, 지평선 쪽은 해 뜰·질 녘(daylight 0.5 근처)에 주황·분홍빛. 구름 몇 덩이(낮에 하얗게), 별(밤에만, `t` 로 천천히 반짝, reduced-motion 이면 멈춤).
  2. **먼 도시** — 지평선 근처 빌딩 실루엣 세 겹, 먼 것일수록 낮고 옅게(낮엔 안개 낀 하늘색 쪽으로). 창 불빛 점은 밤에 많이.
  3. **이 건물의 아래 두 층** — 바닥 판 아래(y −0.5)부터 3.2 씩 두 층, 보이는 두 면(앞 z=d·오른쪽 x=w)에 층 사이 띠·창 격자·기둥, 오른쪽 면은 조금 어둡게.
     불 켜진 창은 밤에 약 55%, 낮엔 8% 가 흐리게 — 나머지는 유리 반사(낮일수록 또렷). 앞면에 1층 입구(밤엔 불빛)와 차양.
  4. **땅** — 건물에 붙은 보도, 그 바깥 잔디, 가로수(입구 앞은 비움). 지평선 아래는 땅 색.
- `daylightAt(date)` — 서울 시각(UTC+9)으로, 계절은 무시하고 6시·18시 앞뒤 1시간에 걸쳐 smoothstep. 0 = 한밤, 1 = 한낮.
- **성능** — 하늘·구름·도시·건물 면·땅은 캔버스 크기의 OffscreenCanvas 하나에 그려 두고, 변환·캔버스 크기·화면 범위·건물 크기·daylight(0.01 단위)가 바뀔 때만 다시 그린다. 매 프레임은 그 그림 한 장 + 별.
- **미리보기** `web/backdrop.html` + `web/props/backdrop.ts` — atlas.json 의 right·up·scale 로 Stage 와 같은 proj 를 만들어 world {35, 32} 로 그리고,
  위에 최상층 바닥 판과 **실제 구운 앞 블록 바닥 그림**을 얹어 각도가 맞는지 본다. `?day=0.3` · `?zoom=2.4` · `?live`, 위에 daylight 슬라이더.

## 왜 · 버린 것

- **지평선 자리** — 등각에는 소실점이 없어 지평선을 어디 둘지 정해야 했다. 땅 높이의 건물 뒤 모서리(proj(0, −6.9, 0))에 두면 건물 양옆으로 먼 도시가 보이고, 세계에 붙어 있어 옮기면 같이 움직인다.
  화면에 붙이는 안(옮겨도 그대로)은 건물만 움직여 따로 노는 것처럼 보였다.
- **도시·별을 화면 범위 안에서만 난수로** — 옮길 때마다 모양이 바뀐다. 세계 좌표의 칸 번호를 시드로 써서 늘 같은 자리에 같은 것.
- **불 켜진 창 수를 daylight 로 늘리기** — 창마다 정해 둔 난수와 문턱(`8% + 47%·밤²`)을 견줘, 저녁이 될수록 같은 창들이 하나씩 켜지게 했다(깜빡이며 바뀌지 않는다).
- **건물 둘레를 실제 모양대로** — 테라스·입구 길로 들쭉날쭉하지만 위층 바닥 판이 덮으니 외곽 직사각형으로 충분.
- **해·달** — 하늘이 캔버스 맨 위로만 보이는 일이 많아 넣지 않았다. 해 질 녘 빛은 지평선 색으로만.
- 처음 짠 것(daylight 없는 판)은 작업 트리가 지워져 커밋 전에 사라졌다 — 대화에 남은 내용으로 다시 쓰면서 daylight 를 넣었다.

## 확인

`npm run typecheck` 통과. vite(8160)로 미리보기를 열어 daylight 0·0.3·0.6·1 과 확대 2.4 를 사진으로 봤다 — 구운 바닥 그림의 모서리가 바닥 판 모서리와 같은 각도로 놓이고,
낮 ↔ 밤이 끊김 없이 이어진다. 미리보기 서버는 내렸다. (사진은 지어낸 건물이라 실을 수 있지만 싣지 않았다 — 붙이면 화면에서 본다.)
