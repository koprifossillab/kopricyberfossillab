# 014 — 상담원 대화창을 메신저처럼

2026-10-23 · `work/20261023-wetherilli-chat` · wetherilli

사용자: 「상담원에게 묻기 칸은 약간 상담원과 메신저로 대화를 하는 듯한 분위기로」. fl-agent-office-3d 세션이 나눠 맡겼다 —
고친 것은 `web/src/Desk.tsx` 와 새 `web/src/desk.css`, 그리고 `Panel.tsx` 의 `Avatar` 에 `export` 한 단어(허락받음). styles.css 는 그 세션이 고치는 중이라 건드리지 않았다.

## 한 것

- **머리** — 상담원 얼굴(목록과 같은 `Avatar`, 구운 머리·몸 조각), 이름은 화면과 같은 `personName({ id: 'desk/상담원' })`, 상태 「온라인」(초록 점)·「답하는 중…」·「연결 확인 중…」, 오른쪽에 「지우기」.
- **말풍선** — 상담원은 왼쪽에 작은 얼굴과 이름, 나는 오른쪽 포인트 색. 같은 사람이 이어 말하면 얼굴·이름은 첫 것에만, 그 첫 말풍선의 위 모서리만 덜 둥글게.
  시각(오후 5:09)은 같은 사람·같은 분의 마지막 말풍선 아래에만. 날짜가 바뀌면 가운데 날짜 줄. 오류는 가운데 붉은 알약.
- **입력 중** — 답을 기다리는 동안 상담원 쪽에 점 셋이 차례로 통통(`prefers-reduced-motion` 이면 멈춤).
- **입력란** — 알약 꼴 textarea(내용만큼 늘어남, `field-sizing`) + 둥근 보내기 단추(종이비행기). 500자 세기는 오른쪽 아래 작게. Enter·Shift+Enter·한글 조합 중 Enter 무시는 그대로.
- **열쇠 넣기** — 같은 머리(「로그인 필요」) 아래 가운데에 안내 두 줄과 알약 입력.
- 색은 테마 변수만(`--panel`·`--bg`·`--accent`·`--accent-fg`·`--line`·`--muted`·`--warn-*`) — 밝은 쪽(조금 밝은 남색)·짙은 쪽 둘 다 봤다.

## 왜 · 버린 것

- **줄 클래스 `desk`** — 처음에 말풍선 줄을 `dk-row desk` 로 했더니 styles.css 의 `.desk`(세로로 쌓는 대화창 틀) 규칙에 걸려 얼굴이 말풍선 위로 올라갔다. 줄은 `by-desk`·`by-me` 로.
- **세기 줄의 사용법 글** — 오른쪽 칸이 좁아(약 210px) 「Enter 보내기 · Shift+Enter 줄바꿈」 을 붙이면 두 줄로 넘쳤다. 숫자만 두고 사용법은 title·aria-label 로.
- **시각을 말풍선마다** — 이어 말하면 시각이 줄줄이 붙어 시끄러웠다. 메신저처럼 같은 분의 마지막에만.
- **Avatar 를 Desk 로 옮기기** — Panel 을 크게 고치게 된다. export 한 단어로 끝냈다(Panel ↔ Desk 가 서로 부르지만 렌더 때만 쓰니 괜찮다).

## 확인

`npm run typecheck`·`npm test`(20)·`npm run build` 통과. `FL_PORT=8159` 로 띄워 열쇠를 localStorage 에 넣고 실제로 세 번 물어
입력 중 점·답 말풍선·날짜 줄·시각·로그인 화면을 사진으로 봤다(사진은 실제 세션 이름이 담겨 싣지 않는다). 다 보고 서버를 내렸다.

## 왼쪽 목록을 부서 상자로

사용자: 「에이전트들이 어느 정도 그룹으로 나눠져서 보기 좋게… GSM 부서인지 다른 부서인지 구분이 되면 좋겠어, 박스 같은 걸로」.
고친 것은 `Panel.tsx` 의 `AgentList` 와 새 `web/src/agentlist.css` — 줄(`Row`)은 그대로 상자 안에 넣었다.

- **묶기** — `room` 이 프로젝트 이름이면 「<이름> 부서」, `center` 는 고객센터(상담원도), `general` 은 공용실(tmux 사람도), `foreign` 은 다른 계정.
  하위 에이전트는 부모 상자 안, 부모 아래(부모가 목록에 없으면 따로 선다). 차례는 프로젝트 부서(이름 차례) → 고객센터 → 공용실 → 다른 계정, 빈 상자는 없다.
- **상자** — 둥근 테두리, 왼쪽 띠 색은 프로젝트 이름의 해시로 `PALETTE` 에서(고객센터는 --accent, 공용실은 --muted, 다른 계정은 FOREIGN_COLOR).
  머리에 이름·사람 수·「일하는 중 n」「확인 필요 n」(없으면 「쉬는 중」). 머리를 누르면 접히고, 접힌 상자는 `kopricyberfossillab.groupsCollapsed` 에 남는다.
- **확인 필요** — 상자 테두리가 붉어지고 이름 옆에 붉은 점, 요약에 붉은 알약. 머리에 있으니 접혀도 보인다.
- **버린 것** — `details/summary`: 열림 상태를 React 가 쥐어야 localStorage 와 맞는데, `open` 속성과 사용자의 누름이 엇갈린다. 단추 + `aria-expanded` 로.
  띠 색을 부서 사람들의 몸 색으로: 한 부서에 색이 여럿이라 띠가 정해지지 않는다.
- **확인** — build·typecheck·test(20) 통과. `FL_PORT=8159` 로 `?demo`(부서 셋 + 고객센터·공용실·다른 계정)와 실제(GSM 부서 여섯, 공용실에 확인 필요 하나)를
  짙은·밝은 테마로 찍어 봤고, 머리를 눌러 접히는 것(줄 8 → 7, localStorage 에 남음)도 봤다. 서버는 내렸다.
