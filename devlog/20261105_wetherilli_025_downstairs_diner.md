# 025 — 아래층 식당가: 반 층 낮은 날개, 계단, 끼니마다 먹으러 가기

2026-11-05 · `work/20261105-wetherilli` · wetherilli

사용자: 「약간 복층 느낌으로 아래 층을 추가하자. 테라스 쪽에서 계단으로 내려가는 식이면 좋을 듯. 아래층엔 식당 — 맥도날드 같은 패스트푸드점,
국밥과 국수를 먹을 수 있는 한식집. 아침(7–8시)·점심(12–14시)·저녁(18–20시)에 확률적으로 가서 주문하고 먹는 모습. 소품, 식사 중 대사,
식사 시간에 일을 시켰을 때 불평하는 대사」.

## 한 것

- **아래층은 따로 짓지 않고 날개 하나** — 테라스 앞(z 가 큰 쪽)에 건물 폭 31×8 모듈 `downstairs` 를 붙이고, 화면이 모듈을 `y = −1.8` 에 놓는다
  (`Placed.y`, `moduleAt`). 굽기는 모듈 안 좌표 그대로라 손댈 것이 없고, 2.5D 에서 「앞이면서 낮은 것」 은 그리는 차례(뒤 → 앞)와도 맞는다.
  높이는 처음 한 층(3.7)으로 잡았다가 사람이 반 층으로 정했다 — 계단이 10단으로 짧아지고, 뒤 벽(1.3)이 테라스 바닥 판 밑에 닿는다.
- **걸음은 2D 그대로, 높이만 덧붙인다** — `world.heightAt(x, z)`: 위층 0, 아래층 −1.8, 계단 층참은 0, 단은 x 를 따라 0 → −1.8.
  nav(A*)는 그대로 평면이고, 계단 옆으로 들어가지 못하게 층참 왼쪽·계단 앞쪽을 막고 테라스 앞 난간에 층참 폭만큼 틈을 냈다.
  시험(`world.test`) — 문·휴게실에서 식당 자리 39곳까지 오가는 길을 0.05 씩 따라가며 높이가 0.08 넘게 튀지 않는지, 계단을 지나는지.
  사람·그림자·고리·이름표·말풍선이 모두 이 높이에 서고, 계단 위를 걷는 사람은 계단 그림이 덮지 않는다(더 낮은 단은 앞에 있어도 발밑).
- **배경(backdrop)** — 날개 밑 1층의 앞·옆 벽과 창을 그리고, 땅·가로수·1층 입구를 날개 앞으로 옮겼다. 날개 뒤의 위층 앞면은 날개 뒤 벽이 가린다.
- **가게 둘** — 「티렉스 버거」(공룡 연구실이라 공룡 버거집 — 초록·귤색, 계산대엔 로고 대신 발자국 무늬)와 「장보고 국밥·국수」(남극 장보고기지에서).
  상표·실제 상호는 쓰지 않았다. 가게 이름은 굽는 그림에 글자를 넣지 않고 이름 기둥(shop_pylon) 위에 HTML 명판으로(`style 'burger'·'gukbap'`).
- **끼니(`meals.ts`)** — 날짜·끼니·사람 id 로 정해 다시 그려도 같은 제비: 아침 40%·점심 85%·저녁 60%, 주문 20~40초, 먹기 5~8분(사람이 정함),
  출발은 끼니 시간 안에 고루 흩고 끝나기 1분 전엔 다 먹는다. 국밥집에선 국밥이나 국수, 버거집 몫은 끼니마다 다르게.
  시각은 화면의 지역 시각(`hourNow` — `?hour=` 로 바꿔 볼 수 있다).
- **연출(`director.ts`)** — 쉬는 사람(하위 에이전트 빼고 상담원 포함)이 뽑히면 카운터·키오스크 앞(`order:<가게>`) → 먹는 자리(`meal:<가게>:<탁자>`).
  자리는 사람마다 정해 둔 곳부터 빈 곳, 반쯤은 이미 누가 앉은 탁자에 끼어 같이 먹으며 이야기한다. 먹다가 바빠지면 일하러 가고 그 끼니엔 다시 오지 않는다(`mealBroken`).
  식탁 위 음식은 붙박이로 굽지 않고 따로 구워(`food-<종류>-<방향>`) 앉은 사람 앞에만 놓는다 — 빈 식탁에 음식이 늘 있으면 누가 먹는지 모른다. 뚝배기·국수엔 김.
- **말(`cast.ts`)** — 식당 무리를 떠날 때 바빠서면 불평(`MEAL_GRUMBLE`), 다 먹어서면 한마디(`MEAL_DONE`). 걸어가는 동안도 보이게 잡담과 따로 `Actor.say`.
  식당 대사(메뉴 고민·줄 서기·맛 칭찬·끼니별·같이 먹기)는 chatter 의 무리 이름과 `Who.meal`·`Who.food` 로 고른다.
- **화면 확인 `?meal`** — 끼니와 상관없이 쉬는 사람이 다 오간다. 예시 데이터는 4초마다 35% 가 활동을 바꿔 식당까지 걸어갈 틈이 없어서, `?demo&meal` 이면 3% 로.
- **가구 시트를 4096 폭으로** — 소품이 늘며 `items.webp` 가 2048×8924 가 되자, 여기 swiftshader 화면에서 휠로 확대하면 모든 모듈 바닥·물건 층이 사라졌다
  (main 의 7059 에선 안 생김). 흔한 GPU 텍스처 한도 8192 를 넘었기 때문으로 보고 4096×4658 로 싸니 없어졌다.

## 나눠 한 것

세션 셋 — 배치·연출·이음과 마무리(이 글), 소품·굽기(`diner.ts`·`models.ts` 의 뒤 벽·바닥 무늬·음식 굽기, a006a7b), 대사(`lines.ts`·`chatter.ts`, 15b3ae1).
이음매는 먼저 정해 보냈다: 무리 이름(`order:<가게>`·`meal:<가게>:<탁자>`), `Who.meal`·`Who.food`, `MEAL_GRUMBLE`·`MEAL_DONE`(string[]), 소품 이름과 크기, `foodKey`.
소품 초안을 배치 쪽이 먼저 써 버려 겹칠 뻔했다 — 파일을 통째로 넘기는 것으로 풀었다. 소품 세션이 끝난 뒤 시트 문제는 배치 쪽이 고쳤다.

## 버린 것

- **아래층을 위층 밑(건물 안 2층)에 두고 위층을 걷어 보이기** — 위층을 반투명으로 하거나 잘라 보여야 해서 지금 그리기(구운 그림 + 가림)와 맞지 않는다. 앞에 붙인 날개면 다 보인다.
- **한 층(3.7) 낮게** — 계단이 20단 6칸 남짓으로 길어지고 화면이 세로로 크게 늘었다. 사람이 반 층으로 정했다.
- **nav 를 3D(층마다 격자)로** — 오르내리는 곳이 계단 하나뿐이라 평면 격자 + 높이 함수로 충분하다. 옆으로 들어가는 것만 막으면 된다(시험이 본다).
- **벽에 거는 가게 간판** — 뒤 벽이 1.3 이라 간판이 테라스 위로 솟는다. 이름 기둥과 HTML 명판으로.
- **점원** — 주문은 카운터·키오스크 앞에 서 있는 것으로 보인다. 점원을 두면 그 사람이 세션처럼 보여 헷갈린다.
- **먹다 불린 사람이 그 끼니에 다시 오기** — 「다시 먹으러 가는」 것도 그럴듯하지만, 곧 다시 불릴 일이 많아 오락가락이 눈에 띄었다.

## 사람이 정할 것

- 없음 — 물음 셋(가게 이름, 높이, 확률·길이)은 다 답을 받았다(이름은 그대로, 높이는 반 층, 먹기는 5~8분).
