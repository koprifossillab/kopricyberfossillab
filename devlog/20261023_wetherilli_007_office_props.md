# 007 — 사무실 소품 25가지: scene/props.ts 와 미리보기(npm run props)

2026-10-23 · `work/20261023-wetherilli-props` · wetherilli

사용자: 「사무실에 넣을만한 다양한 물품 에셋 이것저것」. fl-agent-office-3d 세션이 배치·길찾기를 고치는 중이라
모형만 따로 떼어 이 세션이 맡았다. 같은 작업 트리를 건드리지 않으려고 main 에서 worktree(`-wt-props`)를 따로 냈다.

## 한 것

- **`web/src/scene/props.ts`** — `PROPS: Record<이름, { label, size, build(x, z, rot?) }>`. 25가지:
  - 사무실: 정수기·복사기·책장·서류함·휴지통·옷걸이·벽시계·스탠드 조명·화이트보드(이젤)·서버 랙·지구본·코르크 게시판·
    소형 냉장고·전자레인지 탁자·우산꽂이, 화분 셋(키 큰·다육이·둥근)
  - 연구실: 화석 진열장(유리장 속 삼엽충·암모나이트)·시추 코어 상자·암석 표본 선반·현미경 탁자
  - 낡은 것(칙칙한 방): 찌그러진 철제 캐비닛·쌓인 서류 더미·낡은 선풍기
- **지역 좌표로 그리고 그룹에 자리·방향을 준다** — models.ts 는 세계 좌표를 모형 안에 박아 넣지만, 소품은 여러 자리에
  여러 방향으로 놓일 것이라 `build(x, z, rot)` 가 그룹의 position·rotation.y 만 바꾸게 했다. 앞은 +z, 발은 y=0.
- **벽에 거는 것**(벽시계·코르크 게시판)도 같은 꼴 — 바닥 가운데를 기준으로 높이에 떠 있고, 뒷면이 `z = -size[1]/2`.
  벽 앞 (x, z) 에 놓으면 벽에 붙는다.
- **불빛**(서버 랙 LED·복사기 화면·전자레인지 표시창·스탠드 갓 안)은 `MeshBasicMaterial` — models.ts 의 화면과 같은 생각.
- **미리보기** — `npm run props`. tools/bake.ts 와 같은 길(vite + playwright 1.49.1 chromium, swiftshader)로 `web/props.html` 을
  열어 `docs/props/<이름>.png` 와 한 장 모음 `gallery.png` 를 쓴다. 시점·밀도(VIEW (18,16.5,18), 세계 1 = 96 px)·빛은
  bake/main.ts 와 같게 해서, 갤러리에서 보는 크기가 구웠을 때의 크기다. 바닥 범위(size)는 옅은 사각형으로 보인다.

## 버린 것

- **models.ts 의 bx·mesh·mat 을 export 해서 함께 쓰기** — models.ts 는 다른 세션이 고치는 중이다. 겹치지 않게 같은 꼴을
  props.ts 안에 따로 두었다. 둘이 자리 잡으면 하나로 합칠 수 있다(재질 캐시가 둘이 되는 것 말고는 해가 없다).
- **렌더마다 씬·그림자 빛을 새로 만들기**(bake/main.ts 의 shoot 꼴) — swiftshader 가 CONTEXT_LOST 를 낸다는 말을 듣고
  씬·빛·렌더러는 하나만 두고 물체만 넣었다 빼며, 뺄 때 geometry 를 dispose 한다. 25가지가 1초 안에 끝난다.
- **삼엽충을 선반에 눕히기** — 이 시점에서는 위에서 비스듬히 보여 회색 얼룩이었다. 받침에 기대 앞으로 세우고,
  진열장 뒤판을 밝은 천 색으로 바꿔 화석이 도드라지게 했다. 키운 것(1.4배)은 암모나이트를 가려 되돌렸다.
- **모형마다 그림자 받는 바닥 없이 투명으로** — 벽에 거는 것·낮은 것은 그림자가 없으면 떠 보여 놓일 자리를 알기 어렵다.
  미리보기라 바닥을 깔았다. 실제 굽기는 배치하는 쪽(bake/main.ts)이 한다.

## 남은 것

- 사무실 모듈에 배치·`ITEMS`·`BLOCKS`·굽기는 fl-agent-office-3d 세션이 한다.
- 낡은 캐비닛의 반쯤 열린 문은 이 시점에서 잘 안 보인다 — 놓을 방향에 따라 `rot` 으로 앞을 돌려 보면 된다.
