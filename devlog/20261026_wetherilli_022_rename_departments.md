# 022 — 부서 이름도 두 번 눌러 고치기

2026-10-26 · `work/20261026-wetherilli-2` · wetherilli

사용자: 「부서 이름도 더블클릭해서 바꿀 수 있으면 좋겠어」.

## 어디서 고치고 어디에 보이나

- 왼쪽 목록의 **부서 상자 머리**(「사이버연구실 부서」·「고객센터」·「shkim 계정 부서」…)의 이름을 두 번 누르면 그 자리에 입력란이 나온다.
  Enter·바깥 누르기는 정하기, Esc 는 그만두기, 비우면 정해 둔 이름으로 돌아간다. 사람 이름 고치기(017)와 같다.
- 고친 이름은 **벽 명판**, 세션 줄의 방 이름, 고른 에이전트 칸, 상담원의 상태 요약에도 쓴다. 명판은 매 장면마다 이름을 다시 읽어서 건물을 새로 짓지 않는다.
- 열쇠는 원천의 `room` 값 그대로다: 프로젝트 이름 · `center` · `general` · `foreign` · `@계정`. 줄임말(020)처럼 **원천의 값은 안 바꾸고 보일 때만 바꾼다** —
  방 이름 자체를 바꾸면 사무실 꾸밈(`isRash`·GSM)과 커밋 수 세기가 깨진다.
- 고친 이름은 「… 부서」를 붙이지 않고 쓴 그대로 보인다. 「화석 발굴부」로 고쳤는데 「화석 발굴부 부서」가 되면 안 되니까.

## 서버

- 사람 고치기와 같은 길이다: `PUT /api/people` 에 `{ room, name }`. 받는 것도 같은 규칙이다 — 지금 화면에 있는 방만, 이름은 제어·방향 문자를 빼고 20자, 횟수 제한(60/분)은 사람 고치기와 합쳐서.
- 파일은 `people.json` 옆의 `rooms.json` 으로 따로 둔다. 세션 id 와 달리 프로젝트 이름은 오래 남아서, 사람 기억(500명, 오래된 것부터 잊음)에 섞이면 부서 이름이 밀려날 수 있다. 부서는 200개까지 기억한다.
- `Snapshot.rooms` 로 보낸다(지금 있는 방의 것만). `server/model.ts`·`web/src/types.ts` 둘 다 고쳤다.

## 버린 것

- 명판을 두 번 눌러 고치기 — 명판은 무대 위 글자라 누르기를 받지 않는다(무대를 끌어 옮기는 손짓과도 겹친다). 목록 한 곳이면 된다.
- 부장실·본부장실 명판은 고치지 않는다 — 부서가 아니라 GSM 에 딸린 방이다.
