# 030 — 연구실만 보기 (Esc 로 돌아오기)

2026-11-09 · `work/20261109-wetherilli` · wetherilli

사용자: 「양쪽 탭이랑 위의 바가 보이지 않도록 하는 설정을 만들어줘, 그리고 esc로 돌아올 수 있도록 하자」.

## 한 것

- 설정(⚙) → 「화면」 탭에 「연구실만 보기」 단추. 누르면 설정 창이 닫히고 위 줄(제목·한도·톱니)과 왼쪽 목록·오른쪽 칸이 사라져
  연구실이 창 가득 찬다. 테두리·둥근 모서리·바깥 여백도 뺀다.
- **Esc** 로 돌아온다. 들어간 뒤 3.5초 동안 위 가운데에 「Esc — 목록·위 줄로 돌아오기」가 떴다 흐려진다.
- 켜 둔 것을 `localStorage`(`kopricyberfossillab.focus`)에 남겨, 새로고침해도 그대로다.

## 왜 이렇게

- **저장한다** — 이 화면은 벽 모니터에 띄워 두는 일이 많고, 그런 화면은 가끔 새로고침된다. 새로고침할 때마다 설정을 다시 여는 건 번거롭다.
  대신 들어갈 때마다 Esc 안내를 띄워 「어떻게 나가지」를 막는다.
- **칸을 지우고(렌더하지 않고) CSS 로 숨기지 않는다** — 숨긴 칸도 SSE 마다 다시 그려질 까닭이 없다. 돌아오면 목록이 새로 그려질 뿐이고
  고른 에이전트(`selected`)는 App 이 들고 있어 그대로다. 연구실은 ResizeObserver 로 크기를 다시 맞추니 따로 할 일이 없다.
- **Esc 가 겹칠 때** — 설정·생김새 창도 Esc 로 닫힌다. 그 창이 떠 있으면(`.modal-bg`) 창만 닫고 연구실만 보기는 그대로 둔다.
- 좁은 화면(1000px 아래)은 원래 세로로 쌓고 몸통을 스크롤하는데, 연구실만 보기에선 다시 창 높이에 맞춘다.

## 버린 것

- **브라우저 전체 화면(Fullscreen API)** — 브라우저의 탭·주소창까지 숨길 수 있지만, 사용자 몸짓이 있어야 켜지고 새로고침하면 풀린다.
  묻은 것은 이 화면의 칸이라 거기까지 가지 않았다. 필요하면 브라우저의 F11 과 같이 쓰면 된다.
- 단축키로 켜기(예: F) — 이름표 고치기 등 글 입력과 부딪칠 수 있어 설정 단추 하나로 했다.
