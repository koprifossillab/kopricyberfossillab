# 002 — 2.5D: 3D 를 구워 Canvas 2D 로

2026-10-23 · `work/20261023-wetherilli` · wetherilli

[P02](20261023_wetherilli_P02_isometric_sprites.md) 대로. 사용자와 정한 것: 로우폴리 모양 유지, 갈래 A(지금 3D 를 구워 쓰기).

## 한 것

- **모형을 R3F 컴포넌트에서 three 함수로** — `scene/models.ts`. 굽기만 쓴다. 화면 묶음에서 three·R3F·drei 가 빠져
  스크립트가 1.2 MB → 238 KB(gzip 76 KB). 그림 세 장이 약 490 KB(WebP 0.92).
- **굽기** — `npm run bake` 가 vite 개발 서버 + chromium 으로 `web/bake.html` 을 열어 배경 하나, 가구 19, 캐릭터 272
  (몸 색 9 × 머리 꼴 × 앉음/섬 × 방향 8)를 굽는다. 이 서버에서 24초. 물체마다 카메라가 그 물체의 경계 상자에 꼭 맞게
  정사영 창을 잡으므로 잘라 내기(픽셀 훑기)가 없다.
- **투영은 atlas.json 에서** — 카메라의 오른쪽·위 벡터와 축척(96). 화면은 같은 식으로 (x, y, z) → 픽셀. 3D 판과 좌표가 같아서
  `director.ts`·`nav.ts`·서버는 고치지 않았다.
- **가림** — 배경에는 가구가 그림자까지 다 들어 있다. 캐릭터가 상자 앞이 아니고(x ≤ x1 이고 z ≤ z1) 그림이 겹치면
  그 가구 조각을 캐릭터 뒤에 한 번 더 그린다. 책상의 가림 범위는 의자까지(z+1.25) — 앉은 캐릭터가 의자 앞에 오게.
- **2D 로 그리는 것** — 모니터 빛(활동 색 사각형), 벽 tmux 모니터, 발 그림자, 빨간 링·고른 링, 이름표(HTML).

## 버린 것

- **배경 한 장만 쓰기** — 캐릭터가 책상 뒤로 가면 가려지지 않는다. 그래서 가구를 따로도 굽는다.
- **몸 색을 화면에서 물들이기(tint)** — 조각 수는 17분의 1 이 되지만, 면마다 빛이 다른 로우폴리 음영이 단색 곱하기로는
  그대로 안 나온다. 조각이 272 개여도 312 KB 라 그냥 다 굽는다.
- **서버가 화면을 그려 보내기** — 사용자가 물었다(「서버에 띄워두고 화면만 받아오는 형태?」). 서버 CPU 와 네트워크가 더 든다.
  서버는 그림 파일과 상태만 내주고, 그리기는 브라우저가 한다.
- **드래그 회전** — 고정 시점이 출발점이다. 휠 확대·끌어 옮기기는 2D 로 남겼다.

## 남은 것

- 라운지에 쉬는 세션이 몰리면 이름표가 겹친다(오늘 실제 화면에서 여섯 명).
- playwright 는 1.49.1 로 고정 — 이 서버에 받아 둔 chromium-1148 을 쓰려고. 판을 올리면 브라우저를 새로 받아야 한다.
