# 026 — 식당가 점원과 바깥 손님, 명판은 화면 크기 고정

2026-11-05 · `work/20261105-wetherilli` · wetherilli

사용자: 「매점에 점원을 두고 싶어. 점원이 식사 시간 한 시간 전에 출근해서 음식 준비를 하고, 식사 시간 후 30분 뒤에 퇴근하는 거야.
그리고 점심시간·저녁시간에는 우리 세션을 표현한 사람이 아니어도, 외부에서 상호작용할 수 없는 NPC 들이 와서 식사만 간단하게 종종 하고 가는 연출이 있었으면 좋겠어.」
작업 중에 더 받은 것(판 세션 kopricyberfossillab-16 을 거쳐): 점심 버거집은 점원 둘(카운터·주방), 드나드는 곳은 식당가 엘리베이터, 손님은 한 번에 4~6명,
다 먹은 손님 셋에 하나는 테라스 수족관·공룡 구경, 붐빌 때·한산할 때 점원 대사, 손님의 「일부러 여기까지 와서 먹을 만큼 맛있다」 대사,
그리고 명판을 모두 화면 픽셀 고정 크기로.

## 한 것

- **누가 언제 있나는 `staff.ts`, 어디 서나는 `director.ts`** — 끼니(`meals.ts`)처럼 날짜·끼니·번호로 정해 다시 그려도 같다.
  점원은 끼니 시작 한 시간 전(0~3분 늦기도) 출근 → 준비(prep, 조리대를 40초마다 옮겨 다니며 김·연기) → 끼니 동안(serve) 주문하는 사람이 있으면 카운터 안,
  없으면 카운터와 조리대를 오간다 → 끼니 끝 30분 마감(close, 식탁을 차례로 닦기) → 엘리베이터로 퇴근. 아침 6–8:30 · 점심 11–14:30 · 저녁 17–20:30.
  점원은 가게·자리마다 셋이 날짜와 끼니로 돌아가며 — 한 끼니 동안은 같은 사람.
- **바깥 손님은 무리(혼자 70%·둘 30%) 단위로 끼니에 고르게** — 점심 120·저녁 105 무리, 엘리베이터에서 걸어 10초 + 주문 15~25초 + 먹기 2~4분 (+ 셋에 하나 구경 30~60초와 오르내리기 25초).
  보는 창의 평균이 점심 5명·저녁 4.5명 남짓이 되도록 무리 수를 잡았다(시험이 3.6~6.2 를 본다). 끼니가 끝나기 전에 다 나간다.
- **세션 사람 먼저, 손님은 남은 자리** — `direct()` 가 세션 사람 자리를 다 정한 뒤 `placeExtras()` 가 손님, 그다음 점원(주문하는 사람이 있는지 보고)을 놓는다.
  손님은 처음 볼 때 그 가게 빈자리가 셋(`GUEST_MIN_FREE`) 이상이어야 오고, 오지 않기로 하면 그 끼니엔 끝. 앉을 때는 같이 온 사람 곁 → 빈 탁자 → 세션 사람이 없는 탁자.
  자리는 될 수 있으면 그대로 두되, 세션 사람이 오면 그 사람이 먼저다. 시험은 손님을 넣어도 세션 사람 자리가 손님 없을 때와 똑같은지, 세션 사람으로 가득 차면 손님이 안 오는지 본다.
  테라스 구경도 같은 식 — 그 차례에 세션 사람이 쓴 수족관·먹이 자리 다음 것만. 공룡 먹이 자리에 서면 공룡이 다가온다(먹이는 없다는 대사).
- **엘리베이터** — 식당가 로비 왼 벽(계단 아래쪽 옆)에 `diner_lift`. 점원·손님은 거기서 나타나고 목록에서 빠지면 거기까지 걸어가 사라진다.
  엘리베이터에서 계단 아래 끝으로 비스듬히 오는 길이 끝 단을 옆으로 밟아(높이가 0.1 튐) 시험이 잡았다 — 계단 앞 막기를 아래 끝 0.4 → 0.1 까지 늘렸다.
- **점원은 세션이 아니다** — `Cast` 의 `Actor.npc` 로만 있고 Snapshot·목록·패널엔 없다. 누를 수 없고(누르기 자리에서 뺐다) 이름표도 없다.
  말풍선 위 이름은 「티렉스 점원」·「장보고 점원」·「손님」. 생김새는 id 로만(고칠 수 없다).
- **옷으로 가게를 가른다** — 몸에 `apron` 꼴(셔츠는 가게 색, 허리 아래 두른 앞치마와 끈)을 더 굽고, 머리 층에 모자(`hatKey`) 둘:
  버거집 초록 셔츠·귤색 앞치마·초록 챙 모자, 국밥집 남색 셔츠·생성 앞치마·흰 두건. 모자 밑으로 머리카락이 뚫고 나오지 않게 tmux 모자 사람 목록(`CAP_MALE/FEMALE`)에서 고른다.
  손님은 보통 사람 생김새에 실험 가운만 뺐다.
- **대사(lines.ts·chatter.ts)** — 023 의 섞은 주머니 그대로. 점원 무리 `staff`(가게가 달라도 한 무리 — 버거집 둘끼리, 가게 사이로 말이 오간다)는
  하는 때(준비·마감)와 붐빔(가게에 넷 이상이거나 빈자리 둘 이하면 busy, 하나 이하면 quiet)으로 고르고 쉼이 25~60초로 뜸하다.
  계산대 앞에 점원이 서 있으면 열에 일곱은 점원이 먼저 말을 꺼내 줄 선 사람 하나와 주고받는다(`ORDER_TALKS_*`). 출근·퇴근 인사는 `Actor.say` 로 걸으면서.
  손님은 줄·식탁·수족관·공룡마다 따로, 먹을 때 「일부러 왔다」 류(혼잣말은 가게·음식별, 대화는 가게별)가 넉넉히 섞인다.
- **`?hour=` 가 흐른다** — 전에는 그 시각에 멈춰 있어 손님이 움직이지 않았다. 이제 그 시각에서 시작해 실제 시간만큼 간다.
- **건물이 바뀌면 점원·손님은 새 건물 제자리에서 다시** — 화면을 처음 열 때 빈 목록으로 지은 건물에서 만든 사람이 옛 엘리베이터 좌표에서 위층을 가로질러 걸어왔다.
- **명판은 모두 화면 px 고정(폭 112, 글자 12)** — 전에는 사무실 명판이 문틀 폭(span)에 맞춰 확대와 함께 커지고 글자가 6~15px 로 바뀌었고, 가게 명판은 고정 px 라 따로 놀았다.
  이제 이름표처럼 확대와 상관없이 같은 판·같은 글자, 길면 가운데에 가까운 띄어쓰기에서 두 줄. `span` 은 데이터에 남지만 화면은 쓰지 않는다.

## 버린 것

- **점원을 세션처럼 Snapshot 에 넣기** — 서버를 고쳐야 하고 목록·패널·고치기 창이 모두 「세션이 아님」을 가려야 한다. 화면 안의 연출이라 `Cast` 에만 둔다(server/ 는 그대로).
- **세션 사람과 같은 확률 제비로 손님 뽑기** — 손님 수를 정하기 어렵다. 무리를 끼니 시간에 고르게 깔고 머무는 길이로 몇 명이 있을지 맞추는 편이 「4~6명」 을 지키기 쉽다.
- **팔 움직임으로 조리** — 몸이 방향 없는 원기둥이라 팔이 없다. 잘게 들썩이기와 조리대 위 김·연기로 보인다.
- **손님이 세션 사람 탁자에 끼기** — 세션 사람 자리를 뺏지 말라는 뜻에 맞춰, 같은 탁자는 다른 곳이 다 찼을 때만.
- **식당가 바깥(앞 유리)에 문** — 날개 밑은 1층 건물이라 길이 없다. 엘리베이터가 맞다.

## 0.16.1 — 명판은 문틀 폭에

화면 px 고정(폭 112·글자 12)을 내놓자 「이름 팻말 너무 크다」, 이어 「사무실 명판은 문 틀 가로폭에 맞춘다고 생각해」.
「고정」 은 판과 글자의 비율이 어디서나 같다는 뜻이었다. 그래서 모든 명판을 한 꼴(폭 76·글자 9 — styles.css `.plaque`)로 짓고,
문틀 가로폭(`span`, 없으면 1.4)이 화면에서 차지하는 픽셀에 맞게 통째로 `scale` 한다. 확대하면 문틀과 같이 커지고, 멀리 보면 같이 작아져 겹치지 않는다.
이름이 길면 글자를 줄이지 않고 두 줄로 — 이건 026 그대로.

- **버림: 예전처럼 폭만 문틀에, 글자는 6~15px 로 따로** — 판과 글자 비율이 이름마다·확대마다 달라진다. 사람이 처음 싫어한 것이 그것이다.
- **버림: 멀리서는 명판 숨기기** — 문틀에 맞추면 겹치지 않으니 필요 없다. 다만 처음 화면(건물 전체)에서는 명판이 문틀만큼 작아 글자를 읽기 어렵다 — 확대해서 읽는다.
